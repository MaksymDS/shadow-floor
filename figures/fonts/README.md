# Shadow figure fonts

`Inter-Regular.ttf` and `Inter-SemiBold.ttf` are static instances of the official [Google Fonts Inter variable font](https://github.com/google/fonts/tree/main/ofl/inter), with `opsz=14` and `wght=400` or `600`.

`JetBrainsMono-Regular.ttf` and `JetBrainsMono-SemiBold.ttf` are static instances of the official [Google Fonts JetBrains Mono variable font](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono), with `wght=400` or `600`.

The original variable TTFs are retained as `Inter.ttf` and `JetBrainsMono.ttf`. The static instances were made with fonttools `varLib.instancer`. Both families are licensed under the SIL Open Font License; see the two `OFL-*.txt` files.

These are the exact font families named by Shadow 04. The generator uses the static files to embed the fonts in PDFs without a network request or font installation.
